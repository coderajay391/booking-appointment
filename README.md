## Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd apex-medical
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The application will be available at the local URL provided by Vite, usually:

```text
http://localhost:5173
```

### 4. Build for production

```bash
npm run build
```

### 5. Preview the production build

```bash
npm run preview
```

## Application Overview

Apex Medical is intended to simplify the process of finding healthcare services and booking medical appointments through a modern web interface.

The application's HTML metadata identifies it as **"A modern appointment booking system"**, while the main React application is loaded through `/src/main.tsx`.

## Design

The application uses **Plus Jakarta Sans** as its primary font, giving the interface a modern and clean visual style.

The design should prioritize:

* Clear navigation
* Strong visual hierarchy
* Easy appointment discovery
* Simple booking interactions
* Accessible forms and controls
* Mobile-friendly layouts

## Environment Variables

If the application is connected to an API or backend, create a `.env` file:

```env
VITE_API_URL=http://localhost:5000/api
```

Do not commit sensitive credentials or secrets to Git.

## Development

Recommended workflow:

```bash
npm install
```

Make changes inside the `src/` directory and use the development server for instant feedback.

## Production

Create an optimized production build with:
